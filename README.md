# 🤖 AiCruiter — AI-Powered Interview Assistant for Modern Recruiters

AiCruiter is an **AI-driven recruitment platform** that allows organizations to **automate candidate interviews using voice-based AI agents**.  
It helps recruiters save time, reduce bias, and make smarter hiring decisions — all in one seamless web application.


---

## 🚀 Overview

**AiCruiter** streamlines the hiring process by automating the initial stages of candidate screening.  
Using **AI-powered voice interviews**, recruiters can focus on qualified candidates while AiCruiter handles repetitive tasks like scheduling, questioning, and feedback generation.

### ✨ Key Highlights
- 🎙️ **AI Voice Interviews** — Conduct automated, conversational interviews with Vapi AI.
- 📊 **Data-Driven Insights** — Receive AI-generated analytics and candidate reports.
- ⚡ **Time Efficiency** — Automate initial screening to focus on final-round candidates.
- ⚖️ **Bias Reduction** — Standardized interviews eliminate unconscious bias.
- 🧠 **Smart Job Management** — Create, schedule, and track interviews easily.
- 🔐 **Secure Database** — Built on Supabase for safe and efficient data management.

### ⚙️ How It Works
1. **Create Job** – Add job details (title, description, type, duration). AI prepares the interview questions.  
2. **Share Link** – Generate a unique interview link and send it to candidates.  
3. **AI Interviews** – Candidates interact with the AI interviewer powered by **Vapi**.  
4. **Feedback** – Receive detailed AI-generated feedback and performance reports.
